# About This Project
Have you ever looked up the weather for a trip and seen "25°C and sunny," only to find out it's a bustling concrete jungle when you were expecting a beach? Aura Weather was built to solve that problem. It was born from the idea that knowing the feeling of a place is just as important as knowing the forecast.

This project is a demonstration of modern frontend web development, showcasing the power of integrating third-party APIs into a clean, responsive, and user-centric interface. It’s not just about data; it’s about creating an experience.

Key Features:
Live Weather Data: Instantly fetch and display current weather conditions for any city in the world.
Dynamic Photo Gallery: See what a city actually looks like with a beautiful, responsive grid of photos that updates with every search.
Light & Dark Mode: A seamless theme toggle that respects your system preference and saves your choice.
Recent Search History: Quickly access your previously searched cities, with the ability to remove them.
Fully Responsive: A beautiful and intuitive experience whether you're on a desktop, tablet, or phone.
🛠️ Built With
This project was brought to life using a modern frontend stack, focusing on clean code and a great user experience.

Core Technologies:

HTML5
CSS3
JavaScript(ES6+)
APIs & Services:

OpenWeatherMap API - For providing live weather data.
Unsplash API - For sourcing incredible destination photography.
Key Techniques:

Asynchronous JavaScript (async/await) for non-blocking API calls.
CSS Variables for powerful and easy theming.
Browser localStorage for persisting user preferences.
Flexbox & CSS Grid for modern, responsive layouts.
